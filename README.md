# Comercio Electrónico - React + Firebase

Aplicación web de comercio electrónico desarrollada con React y Firebase.

## Tecnologías utilizadas
- React JS
- Vite
- Firebase (autenticación y base de datos)
- Axios
- JavaScript

## Funcionalidades
- Registro e inicio de sesión de usuarios
- Listado de productos
- Alta y modificación de productos
- Navegación entre páginas con React Router
- Conexión a API externa con Axios

## Tipo de proyecto
Proyecto final del Diplomado en React JS — Universidad Tecnológica Nacional (UTN).
